1 基本信息表
2 作品功能与性能说明
系统提供内容登记、发布、传播、验证、撤销、版本派生和攻击演示。登记阶段使用本地受信公钥清单，发布阶段固定遵守“随机 ContentID → 水印嵌入 → 最终编码字节 → SM3 → JCS Manifest → SM2 → SQLite 登记”的顺序。验证阶段支持 hard、recover、full 三种模式，未执行的检查保持 NOT_CHECKED，状态快照不可用时返回 UNKNOWN。
3 设计与实现方案
图 1  总体架构。水印进入媒体像素或页面渲染内容，SM3/SM2 对最终发布字节和 Manifest 提供来源与完整性证据。
ContentID 是登记发布版本的随机标识。Manifest 正文包括媒体类型、最终字节长度与 SM3、元数据摘要、父版本、允许变换、水印 profile、签名套件和 SM2 用户标识。规范化采用 RFC 8785 JCS，签名消息使用固定协议域分离前缀与 canonical body。发布者信任、签名有效性和状态新鲜度分别保存，避免把有效签名自动等同于受信发布者或最新未撤销状态。
图 2  联合验证流程。水印是传播后识别线索，不能替代 SM3/Manifest/SM2 的来源和完整性证据；恢复到旧 ContentID 后，当前摘要不匹配时只报告 ORIGIN_HINT_ONLY。
4 运行结果
真实 PDF 验收使用本地已保存的真实论文 PDF 第一页，在隔离 Registry 中完成一次登记与发布。服务层 hard 验证确认 Manifest、SM2 签名、受信发布者、最终 PDF 摘要、根版本链和授权字段；随后 PDF 页面按 120 DPI 渲染，嵌入 watermark-v1，写出 PNG 页面并从最终编码字节盲恢复本次 ContentID。该运行的 page_count=1、status=PASS、registration_allowed=true，日志同时记录页面级 SM3 和完整 PDF 凭证验证字段。

5 技术指标
口径说明：992/1000 是 1000 次端到端发布尝试通过最终 gate 的比例；只有这 992 个已发布字节进入 D0 检测，因此 992/992 是 gate 通过子集的正确恢复率，不是 1000 个样本的总体恢复率。中心 95% 裁剪 S0 为独立传播鲁棒性实验，48/80 仅表示该裁剪子集的来源线索恢复结果。
8 条拒绝分为两类：wikimedia-artemis-earthrise 与 wikimedia-earth-from-space 是超过 16MP 的输入约束拒绝；r8-img-0058、0142、0178、0226、0394、0520 是最终编码字节未恢复本次 ContentID 的发布 gate 拒绝。六个内容恢复失败样本的三配置有界诊断见 submission/logs/round9/gate-failure-diagnostics.md；生产 G3 在 gate 前失败，没有生产 ContentID，因此诊断 CID 只用于可复现分析，不回写 Round9 统计。
存储开销按评测日志分开统计：992 个最终发布字节合计 824,071,188 bytes；隔离 Registry JSON 4,200,469 bytes、SQLite 425,943,040 bytes、状态快照 616,028 bytes。后面三项是逐样本评测隔离开销，不等于产品部署 footprint。PDF 固定质量诊断覆盖 10 份文档、27 个页面：MSE 均值 537.942194，PSNR 均值 20.963666 dB，SSIM 均值 0.878221；文字层 10/10 丢失，书签 10/10 丢失。
6 系统测试与结果
测试覆盖密码后端、Manifest/JCS、Registry、图片水印、PDF 安全攻击、版本链、撤销、API、CLI、截图任务和本次 PDF 栅格化模块。新增 PDF 测试包含单页、三页逐页验证、确定性渲染、JPEG/PNG 重编码、尺寸参数、最终编码 gate 失败回归和服务回调。真实验收脚本还覆盖内容替换、Manifest 篡改、签名伪造、旧版本回滚、撤销复用等既有安全测试入口。
7 应用前景与结论
系统可部署在普通 CPU 电脑，用于内容来源登记、内部发布审核、传播副本溯源和版本撤销查询。它适合把上传文件与已签名声明建立可审计关系，并为截图、重编码和 PDF 页面传播提供有限来源检索能力。PDF 栅格化模式会牺牲文字可搜索性、书签、链接和编辑能力，适用时应把原始 PDF 与发布页面副本分开保存。
当前结论由最终字节摘要、Manifest、SM2 签名、发布者信任、版本链和状态快照共同决定。水印可能被移除、损坏或复制，恢复 ContentID 不能单独证明当前内容完整、真实、合法或属于某位作者。系统不证明内容真实、合法、无偏见，也不把水印单独当作法律上的作者身份证明。后续工作包括补充可核验 AI/外部 PDF 来源、完善多页页面身份清单、降低裁剪同步延迟、恢复全量 pytest 环境并扩展音视频能力。
