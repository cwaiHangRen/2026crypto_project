# 架构与数据流

`cli` 与本地 FastAPI 共享 `service`。服务层生成 ContentID、调用媒体适配器嵌入，随后对最终文件完整字节计算 SM3，构造 RFC 8785 JCS Manifest，调用 OpenSSL 适配器完成 SM2-SM3 DER 签名，最后通过 SQLite 事务登记。

验证按层返回结构化状态：Manifest 结构、签名、受信、完整字节摘要、水印来源线索、父链、撤销和状态新鲜度互相独立。sidecar 丢失时 `recover` 仅用盲水印查索引；恢复到的 ID 不自动等于完整性通过。

图片基线采用 512×512 归一化的 8×8 DCT 低频系数差、重复和 RS 纠错。PDF 适配先逐页栅格化并嵌入同一图片水印，明确记录会丢失文字层的限制。
