# 第三方组件与许可证

* OpenSSL：Apache License 2.0，系统命令行实现 SM2/SM3；本项目不复制其源码。
* Python、NumPy：PSF / BSD；Pillow：HPND；pypdf：BSD；pypdfium2：Apache-2.0 或 BSD-3-Clause；ReportLab：BSD。
* SciPy：BSD-3-Clause；使用其 DCT 与 ConvexHull 生成有限几何校正候选，二进制包中附带组件的许可见安装包清单。reedsolo 1.7.0 的包元数据标记 Public Domain；使用真实 RS(53,21) 解码与擦除接口，不复制源码。
* RFC 8785 规范作为协议依据；使用的序列化实现和版本在 `doctor` 与 `pyproject.toml` 中记录。

版本和许可证以实际环境清单为准，项目不声称 C2PA 兼容认证。
